# WinLents

Приложение в стиле TikTok: вертикальная лента (свайп вверх/вниз), лайки (в т.ч. двойной тап),
комментарии, «Интересное», «Входящие», профиль. Написано на Python + Flet, собирается в .apk.
Все ассеты (логотип, иконки, кнопки, фоны) нарезаны из твоего макета.

## Запуск на ПК (проверка)

```bat
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
flet run src\main.py
```

## Сборка .apk

```bat
.venv\Scripts\activate
flet build apk
```

Готовый файл: `build\apk\*.apk`. При первой сборке Flet сам скачает Flutter, JDK 17 и Android SDK
(нужен интернет и несколько ГБ места), поэтому первый раз она долгая.
Если Flutter ругнётся на symlink — включи «Режим разработчика» в Параметрах Windows.

Установка: скопируй .apk на телефон (разреши установку из неизвестных источников)
или `adb install build\apk\app-release.apk`.

## Структура

- `src/main.py` — всё приложение
- `src/assets/` — иконки, логотипы, фоны ленты, `icon.png` (иконка приложения)
- `tools/prepare_assets.py` — скрипт, которым ассеты нарезаны из `tools/design.png`


## Автоматическая сборка APK через GitHub

1. Загрузи содержимое этого проекта в GitHub-репозиторий (в корне должны лежать `pyproject.toml`, `requirements.txt`, `src/` и папка `.github/`).
2. Открой вкладку **Actions**. При `push` в ветку `main` или `master` сборка запустится автоматически. Также её можно запустить вручную через **Build Android APK** → **Run workflow**.
3. Дождись завершения workflow с зелёной галочкой.
4. Открой завершённый запуск workflow, прокрути до **Artifacts** и скачай **WinLents-APK**. Внутри будет `.apk`.

Если сборка завершится ошибкой, открой шаг **Build APK** в Actions и посмотри лог ошибки. Первый запуск может занять несколько минут.
